# CLAUDE.md

Guidance for AI assistants (and humans) working in this repository.

## What this repository is

`xtc-assets` is an **asset repository**, not a software project. It stores
binary 3D/media assets for the "XTC" brand. There is no source code, build
system, package manager, test suite, or CI configuration — do not look for or
invent one.

## Conventions

- **Naming:** asset files use lowercase, hyphen-separated names with a
  brand/subject prefix — e.g. `bag-xtc.glb`. Follow this pattern when adding
  new assets (`<subject>-xtc.<ext>`).
- **Format:** prefer self-contained GLB (`.glb`) for 3D models so textures
  travel inside a single file. If you must use separate `.gltf` + `.bin` +
  texture files, keep them together in a dedicated subdirectory.
- **Provenance & licensing:** every third-party asset must retain its author,
  source URL, and license. For glTF assets this lives in `asset.extras`; do not
  strip it. Record the same information in this file's contents table when you
  add an asset.

## Working with GLB files

There is no toolchain checked in, so inspect assets directly. Quick metadata
dump with the Python standard library (no dependencies):

```python
import struct, json
with open('bag-xtc.glb', 'rb') as f:
    data = f.read()
_, _, length = struct.unpack('<III', data[:12])   # magic, version, length
clen, _ = struct.unpack('<II', data[12:20])         # first chunk = JSON
gltf = json.loads(data[20:20 + clen])
print(json.dumps(gltf['asset'], indent=2))
print('meshes:', [m['name'] for m in gltf.get('meshes', [])])
print('materials:', [m['name'] for m in gltf.get('materials', [])])
```

To view a model visually, load it in any glTF viewer (e.g.
<https://gltf-viewer.donmccurdy.com/>), Blender, or a `three.js` scene. These
are not installed here — do not add a viewer or dependencies unless asked.

## Git workflow

- Assets are **binary** — diffs are not meaningful, so review changes by
  inspecting the file (size, metadata) rather than reading a text diff.
- Because binaries bloat history, avoid committing throwaway or intermediate
  exports. Commit only final, intended assets.
- Commit messages should name the asset and what changed
  (e.g. `Add hoodie-xtc.glb` or `Re-export bag-xtc.glb with fixed zipper material`).
- If large binary assets become numerous, consider Git LFS — but do not
  introduce it unilaterally; confirm with the maintainer first.

## Guardrails for AI assistants

- Do **not** fabricate build/test/lint commands — there are none.
- Do **not** modify a `.glb`/`.gltf` binary blindly (e.g. via text edits);
  regenerate it from a proper 3D tool and replace the whole file.
- Preserve embedded `asset.extras` provenance and license metadata.
- Keep this file's contents table in sync when assets are added, removed, or
  renamed.
