# XTC emoji — свэг-библия (v3)

Выведено из бренда живьём: `products/*` (лонгсливы day/night, louverse tank, LATEXX, ремень 9 цветов), `gallery/latexx` (ночной паркинг, вспышка, серебро), `gallery/drop-00` (SWAG из ремней на кровати, крест-лого), `drop/` (flip-clock, закреп-табло), `app/psp`.

## Что такое XTC в одной строке

**Вещь и материал в ночной вспышке.** Латекс тянется и бликует, хром звенит, люверс защёлкивается, молния едет, табло щёлкает, ткань висит. Эмоцию несёт предмет и его физика, а не морда. Монохром как дорогой печатной знак: жирный силуэт, негативное пространство, одна кульминация.

## Правки клиента после v3.0 (в силе)

- **Только наши знаки.** Любой X, XTC или крест в паке — это логотип 1:1 (`fonts/xtc-logo.svg`, трассировка брендового файла; `xtc/logo.py`) в **одной пропорции 2.2:1 и одной жирности** — бокс только ограничивает размер, никогда не растягивает букву. Никаких шрифтовых X, никаких чужих слов на табло (LOL/OMG/OK/GM…): табло только с X·T·C и DROP.
- **Лиц два: X_X и «опиумная» морда** (глаза-лезвия + черта, референс клиента). Всё в паке — «опиумное»: тёмное, острое, минимальное, почти без движения там, где вещь тяжёлая.
- **Ремни и штаны — нет.** Предметка: таблетка, крест, печать, вспышка, лонгслив, louverse tank, таймер, табло DROP, плитки, коробка, купюры, PSP, сумка.
- **Тату-капсула v1 — да:** ключ, мишка с костями, трайбл-сердца, сигилы (паук, скорпион, око, крест, крылья, ошейник). Их анимация — по тем же правилам веса и кульминации.

## ДА

1. **Предмет вместо морды.** Если эмоцию можно сказать вещью бренда (ремень, люверс, молния, латекс, табло, лого), говорим вещью. Лицо остаётся только там, где без него смысл эмодзи не передать, и оно должно быть «предметным»: глаз = люверс, рот = табло/молния, слёзы = подтёки латекса.
2. **Материал читается на 24px.** Латекс = блик-вырез бежит по форме (1 матт), объём сохраняется при растяжении. Хром = ✦-кант на кромке ровно в кадре разворота. Резина = jelly с затуханием ×0.4–0.6. У каждого эмодзи один материал, и он виден.
3. **Тяжёлое движение.** Антиципация 11–20f, удар 5–13f, контакт 1f, досадка 2–3 колебания, 20–30% лупа почти покой с микродыханием. Вещь весит, инерция видна.
4. **Одна кульминация, максимум 2 акцента одновременно.** Каждый кадр отвечает на вопрос «на что смотреть».
5. **Негативное пространство как приём.** Дырка = цвет фона чата: вспышка-засвет, свет из прорезей, экран, люверс насквозь. Белого нет, есть отсутствие чёрного.
6. **Лого-ритуалы.** X, XTC, крест X·XTC·C ставятся как печать, штамп, клише, гравировка на пряжке, не как «подпись в углу».
7. **Жирный силуэт печатного знака.** Штрих W=46, минимальная деталь 28px, силуэт 88–92% холста, один оптический вес на весь пак.

## НЕТ

1. **Стоковые тропы**: колпак-хлопушка, клоун, нимб, ботан-очки, моаи-мем, o7, «мультяшные руки», дудка, пузырь из носа.
2. **Kaomoji ради kaomoji.** Три одинаковых лица с разной бровью — это одно лицо. Глаза-кольца «0_0» в паке ≤ 3.
3. **✦-звёздочки — нет вообще** (клиент v3.4: «меньше звёздочек, чтобы дорого»). Материал показывает только бегущий блик-вырез.
4. **Глаза на предметах.** Сумка с глазами — не XTC.
5. **«Всё трясётся».** Jitter только как удержание напряжения перед кульминацией, не как фон.
6. **Мелкий шум**: штриховки, точки, пунктир, буквы < 28px по штриху, семь букв в строке.
7. **Прыг-скок ради движения.** Подпрыгивание без веса, качание синусом, «пульсирует» как единственная идея.

## Палитра приёмов (что делает дорого)

| приём | где применять | как |
|---|---|---|
| латексный блик | лак, сердце, штаны, визор | `M.glare_sweep`: 1 матт, двойной штрих под −35°, 24–34f на пике покоя |
| хром-кант | пряжка, молния, PSP, табло | ✦ на кромке ровно в кадре, где грань разворачивается к камере, 18–24f |
| щелчок | люверс, пряжка, молния, флап | контакт 1f 108/92, кольцо-волна stroke 22→4 за 12f, досадка +7 −3 +2 |
| вспышка-засвет | ночной паркинг | 1–2 кадра всё белое (дырка), потом чёрное «проявляется» |
| табло | текст | split-flap `M.flip_tile`, толчок корпуса 102/97 через 6f после флапа |
| fake-3D | плоские вещи | `M.spin3d`: ускорение (0.3,0,0.14,1), торец, ✦ на выходе лицом |
| настоящий 3D | профильные вещи | bpy Cycles + potrace, 24–36 поз |
| подтёк | латекс тает, слёзы, слюна | набухание is → срыв snapo → капля по дуге |
| перемотка | взрыв, распад | всё летит обратно, луп закрыт (M21) |

## Свэг-тест (каждый эмодзи обязан ответить «да» на все 5)

1. **Вещь?** Можно назвать материал или предмет XTC, который здесь главный?
2. **Дорого?** Есть вес, антиципация и досадка, или это «картинка дёрнулась»?
3. **Одна кульминация?** Указать кадр, на который смотрят. Второго такого кадра нет.
4. **24px?** Смысл и эмоция читаются в тексте без подписи, с базовым Unicode совпадает.
5. **Отправил бы?** Друг получит и поймёт, что это XTC, а не стандартный смайл.

Не прошёл хотя бы один пункт → REDO с новым концептом (не подкрутка ключей); не прошёл после двух → CUT.
