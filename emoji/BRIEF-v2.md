## ПРОВЕРЕННЫЕ ФАКТЫ (уже выяснено экспериментом — не перепроверяй, опирайся)

- **v1 в Telegram сломан:** 28 из 36 файлов проходят валидатор, но в rlottie (движок Telegram на всех платформах) рендерят пустоту/замирают/съезжают в угол. Три причины — теперь это жёсткие правила формата, `qa.py` их ловит:
  1. статичные `ks.o` и `ks.r` записаны массивом `[100]` → слой не рисуется. Статичные 1D-свойства — **скаляр** (`"k": 100`);
  2. ключ без `i`/`o` easing (кроме последнего) → анимированный scale = слой пропадает, rotation/position = замирает. **Каждый ключ, кроме последнего, имеет и `i`, и `o`**;
  3. у **последнего ключа есть `i`** → ломается всё свойство. Последний ключ = только `t` + `s`.
  После этих трёх правок 35/36 v1 рендерятся (02 — капли уходят за нижний край холста).
- **Adaptive-перекраска берёт только альфу** кадра и заливает её цветом текста (исходники Telegram Desktop: `colorizeImage(..., useAlpha=true)`). Следствия: цвет заливки не влияет, влияет прозрачность; **«белая деталь» внутри чёрного невозможна — только дырка** (evenodd или матт); полупрозрачность = более бледный цвет текста. Цвета всё равно держим `#000000` (iOS/Android не проверены; `qa.py` требует `#000`).
- Валидатор Telegram (python-lottie `tgs_validator`): fps 30/60, 512×512, ≤180 кадров, ≤64 KB — ошибки; skew, 3D, text/image-слои, эффекты, auto-orient, merge paths, time remap — запрещены; masks/mattes, star, repeater, gradient stroke — «официально не поддерживаются» (Note).
- **Проверено в rlottie, работает:** trim path, shape-морф (одинаковое число вершин), `parent`, подмена слоёв через `ip/op`, inverted alpha track matte (`td:1` + `tt:2`) — блик-вырез рендерится корректно, но это Note → **максимум 1 матт на эмодзи и только там, где без него никак**.
- **Fake-3D «монета»** (scaleX = cos θ + торец + подмена лица) рендерится чисто, ~1 KB.
- **Настоящий 3D-turntable работает:** `pip install "bpy==4.5.*"` (Blender 4.5 LTS как модуль Python 3.11) + `apt install potrace`. Рендер **Cycles CPU** (Workbench/EEVEE падают без libEGL), `film_transparent`, орто-камера с запасом кадра; у glTF — корневые Empty, крутить надо **корень**, а не меши. Трассировка: `potrace -s -u 1 -t 20 -O 1.0`, в SVG заменить `512.000000pt` → `512`, импорт `lottie.parsers.svg.parse_svg_file` — позиция 1:1 с PNG. 36 поз сумки = **8 KB**. Детали (молния) — вычесть отдельным проходом рендера как дырки. **Но**: у плоской сумки силуэт на повороте — сужающийся прямоугольник, не лучше fake-3D. Настоящее 3D — только для объектов с узнаваемым силуэтом в профиль.
- Установка: `pip install rlottie-python pillow`; `SETUPTOOLS_USE_DISTUTILS=stdlib pip install lottie` (обычный `pip install lottie` падает на новом setuptools).
- **Читаемость v1 на 24px** (проверено листом): мёртвые/каша — 23 dot-star, 24 mask-engraving, 30 club-banner (текст), 17 winged-x, 27 tribal-x, 03 sigil-x, 04 tramp-stamp, 21 teddy-skull, 31 cyber-butterfly, 43 scorpion, 33 kao-xx и 42 kao-tongue (тонкие X-глаза). Читаются хорошо — 01, 02, 10, 14, 15, 16, 18, 19, 20, 22, 25, 26, 29, 32, 34–41. Kaomoji — узкая полоса по высоте (~20% холста): на 24px мелкие, делай глифы крупнее и жирнее.
- Не проверено (сеть к core.telegram.org была закрыта): точные лимиты именно custom emoji (исхожу из тех же 512/60/≤3с/64KB, v1 так и заливался), лимит 200 эмодзи на пак, флаг `needs_repainting` в Bot API. Если есть доступ — сверь за 2 минуты, не больше.

Фирменная предметка (см. `xtc-context.png`):

- **Louverse tank top** — `XTC` выложено **люверсами** (металлические кольца).
- **100% LATEXX** — лаковые штаны: жёсткий глянец, блики, люверсы, молнии.
- **Ремень с люверсами** и массивной пряжкой, 9 цветов.
- **Логотип-крест**: `X` сверху, `XTC` горизонталью, `C` снизу.
- **Таймер дропа** — flip-clock `ДД ЧЧ ММ`. **Закреп канала** — флип-табло: `XTC → PAY → ME → DROP → NOW`.
- Мини-апп в корпусе **PSP-3000**; 3D-сумка; съёмки — ночной подземный паркинг, вспышка, серебро.

Мотивы — не «логотипные эмодзи для галочки», а материал, который **раздувается в эмоции**. Из каждого мотива выжми 2–3 разные эмоции:
- люверс = глаз (kaomoji с глазами-кольцами, моргают сжатием кольца); люверсы выщёлкиваются по одному, собирая слово;
- латексный блик = фирменный «дорогой» акцент: ✦-вспышка на кромке + диагональные штрихи через прорези/линзы; блик-вырез по сплошному — через 1 матт (см. факты);
- флип-табло = механика всех текстовых бейджей: буквы перещёлкиваются половинками (fake-3D по X, `scaleY = cos θ`);
- flip-clock = ожидание; пряжка = «договорились/застегнись»; крест = «аминь/благословляю»; лонгслив на вешалке = «хочу/sold out»; PSP = «играю/залипаю».

## 360-ВРАЩЕНИЕ — ФИРМЕННЫЙ «ВАУ», 8–12 ЭМОДЗИ

- **Плоские объекты** (монета-таблетка 01, крест-лого, пряжка, люверс, пластырь 41, ключ 10, звезда 19, бейджи): поворот вокруг вертикальной оси `scaleX = 100·cos θ` по кривой разгон → поворот → торможение с overshoot; на 90°/270° подмена лица на оборот (через `ip/op` или opacity в кадре, где ширина ≈ 0); **торец** — отдельный слой-полоса шириной ≈ толщина·|sin θ| у ведущего края — даёт объём; `scaleY` 102–104% на ребре, ✦-блик на кромке при развороте лицом. 360° + удержание лицом, или 720° с затуханием.
- **Flip по X** (табло, цифры): `scaleY = cos θ`, верхняя половина падает на нижнюю, смена символа на ребре.
- **Объёмные с узнаваемым профилем** — настоящий turntable по рецепту из ФАКТОВ (24–36 поз, неравномерный тайминг с разгоном/торможением, симметричные позы — зеркалом `scaleX −100`, ≤64 KB). Сумку из `bag-xtc.glb` делай fake-3D, если turntable не даёт выразительного профиля.
- Вращение должно ощущаться тяжёлым и дорогим (инерция, торможение, микро-отскок), а не «картинка сжалась-разжалась».

## ТЕХНИЧЕСКИЕ РАМКИ

- TGS = gzip Lottie JSON, `v: "5.5.7"`, без `meta`. 512×512, `fr: 60`, `ip: 0`, `op` 60–180 (1–3 с). ≤64 KB (цель 3–20 KB).
- **Формат ключей и свойств — правила из ФАКТОВ (скаляры для статичных `o`/`r`; `i`+`o` на каждом ключе, кроме последнего; последний — только `t`+`s`).** Easing — кастомные безье; не запекай анимацию ключом на каждый кадр: меньше ключей с правильными кривыми = плавнее и легче.
- Все заливки/обводки `#000000`. Тон — только opacity. Белого внутри нет — только дырки (evenodd `r: 2` или 1 матт).
- Разрешено: `parent`, осмысленные anchor `a` у каждого слоя, групповые трансформы, `ip/op` слоёв, shape-морф с одинаковым числом вершин, trim path, precomp без time remap.
- Запрещено: всё из списка валидатора в ФАКТАХ, expressions, skew.
- Луп замкнут: кадр op ≡ кадр 0; ни одного пустого кадра; арт в поле 8px на всех кадрах (`qa.py` проверяет).

## ЯЗЫК ДВИЖЕНИЯ «XTC MOTION»

- Темп 120 BPM → бит = 30 кадров. Базовый луп 120 кадров; сюжетные (сон, таяние, взрыв мозга, 360) — до 180. Акценты — на битах.
- Ритм: **действие → удержание → акцент**. Минимум 20–30% лупа — почти покой с микродыханием (scale 99–101%). Равномерная постоянная качка = дёшево.
- 12 принципов: anticipation перед крупным движением, overshoot + затухающий settle (2–3 колебания), squash & stretch с сохранением объёма (sx·sy ≈ 1), smear 1–2 кадра на быстрых движениях, follow-through/overlapping (вторичное отстаёт на 4–10 кадров), движение по дугам.
- Частицы — главный «дорогой» слой: слёзы, пот, пар, zZz, искры, конфетти, сердечки, «!», «?», линии удара. Рождаются со stagger, летят по дуге, гаснут scale+opacity, возвращаются к старту лупа невидимо.
- Anchor каждого слоя — в физической точке вращения (корень крыла, верх маятника, центр глаза), не в центре холста.
- Моргание: scaleY глаза 100→8→100 за 6–8 кадров, anchor в центре глаза, раз за луп, не на такте с другим акцентом.

## СБОРКА

- `build.py`: декларативный спец на эмодзи (слои, anchors, parent, ключи) + библиотека моушна (`ease`, `squash`, `settle`, `blink`, `drip`, `particle_burst`, `heartbeat`, `shake`, `smear`, `twinkle`, `coin_flip`, `flap_flip`). Библиотека **сама пишет ключи по правилам формата**. Правка = правка спеца и пересборка одного файла.
- Исходники → `src/NN-name.svg`, результат → `tgs/NN-name.tgs`.
- После каждой пачки — `python3 qa.py tgs/ --sheets sheets/`. Технический PASS ≠ готово; готово = PASS + порог шкалы.
