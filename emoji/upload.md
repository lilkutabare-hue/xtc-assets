# Заливка XTC emoji v3 в Telegram

Порядок в паке задаёт `manifest.csv`: первая строка — обложка (`01-pill-x`), дальше бренд-предметка и DROP (в том числе плитки-пазл 131–133: подряд в тексте складываются в табло X T C) → 14 лиц → реакции → тату-капсула v1 → бейджи-табло.
Все `.tgs` прошли `qa.py` (валидатор Telegram, линт под rlottie, рендер rlottie, поле 8px, шов лупа).

Не проверено: core.telegram.org закрыт прокси сессии, поэтому лимиты custom emoji сверить не удалось. Проверено через Bot API (uploadStickerFile, v3.30): TGS для custom emoji — холст **512×512** как у стикеров (100×100 сервер отвечает «wrong file type»), `"tgs": 1` в JSON обязателен, 60 fps, ≤3 с, ≤64 KB. Лимит скорости: ~10 загрузок подряд, потом `retry_after` ≈ 5 мин — лить с паузой 2–3 с. Лимит 200 эмодзи на пак тоже не проверен: сейчас в паке меньше 200. Плитки 131–133 привязаны к 🇽 🇹 🇨 (regional indicator); если @Stickers их не примет, ставь ✖️ ➕ ©️.

## Путь 1: вручную через @Stickers

1. `/newemojipack` → тип **Animated emoji**.
2. Если бот спросит про цвет или adaptive, включи **«адаптивный / цвет текста»**. Заливать нужно до первого файла. Все файлы чёрные `#000000`, перекраска берёт только альфу.
3. Отправь `tgs/<file>` из `manifest.csv` **документом** (файлом, не стикером), строго по порядку.
4. На каждый файл бот спросит эмодзи. Отправляй колонку `emoji` той же строки.
5. После последнего файла `/publish`. Иконку пропусти: ей станет первый эмодзи. Короткое имя придумай сам, например `xtcpayme`.
6. Проверь в клиенте:
   - [ ] пак ставится по ссылке `t.me/addemoji/<имя>`;
   - [ ] в светлой и тёмной теме эмодзи окрашиваются в цвет текста;
   - [ ] в пикере (≈100 px) и в тексте (≈20 px) нет пустых кадров;
   - [ ] обложка — таблетка ⊗.

## Путь 2: скриптом через Bot API

```bash
BOT_TOKEN=123:abc TG_USER_ID=<твой user id> python3 upload.py xtc "XTC" manifest.csv
```

- Создаёт `createNewStickerSet(sticker_type="custom_emoji", needs_repainting=true)` с первыми 50, остальные добавляет через `addStickerToSet`.
- В keywords идут `keywords_ru` + `keywords_en` вперемешку, обрезанные до лимита API: 20 штук и не больше 64 символов суммарно.
- Минус этого пути: имя пака получит суффикс `_by_<bot>`, так требует Telegram для паков, созданных ботом.
- Повторный запуск с тем же именем докидывает недостающие эмодзи.
- Бот должен быть твоим: `TG_USER_ID` станет владельцем пака, и с этого аккаунта нужно хотя бы раз нажать /start у бота.
